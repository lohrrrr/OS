# Шпаргалка: файлы, маски, поиск и справка

| Команда | Назначение | Безопасный пример | Опасный вариант и риск |
|---|---|---|---|
| `pwd` | Показать текущий каталог | `pwd` перед удалением | Не проверять путь перед `rm` — удалить не те файлы |
| `ls -la` | Показать файлы, включая скрытые | `ls -la ~/files-lab` | `ls *` пропускает скрытые файлы |
| `mkdir -p` | Создать дерево каталогов | `mkdir -pv sorted/{docs,data}` | `mkdir` без проверки пути создаст дерево не там |
| `touch` | Создать файл или обновить время | `touch -- "notes draft.txt"` | `touch` по неверному имени создаст лишний файл |
| `cp -i` | Копировать с подтверждением перезаписи | `cp -i source.csv backup/` | `cp source.csv backup/` может молча заменить данные |
| `mv -i` | Переместить или переименовать с подтверждением | `mv -i "my report.txt" my-report.txt` | `mv` с неверной целью может заменить существующий файл |
| `rm -i` | Удалить файл с подтверждением | `ls -- *.bak; rm -i -- *.bak` | `rm -f *` может удалить все совпавшие файлы без вопроса |
| `rmdir` | Удалить только пустой каталог | `rmdir empty-dir` | `rm -r dir` удаляет всё дерево без возможности отмены |
| `find` | Искать файлы по условиям | `find . -type f -name '*.txt' -print` | `find / -delete` может удалить системные файлы |
| `locate` | Искать по индексу имён | `locate -e os-release` | Устаревший индекс может ввести в заблуждение |
| `updatedb` | Обновить индекс `locate` | `sudo updatedb` после изменений | Запуск без понимания источников индексирует лишние каталоги |
| `which` | Найти исполняемый файл в `PATH` | `which bash` | Полагаться на найденный одноимённый файл из непроверенного каталога |
| `type` | Определить тип команды | `type cd; type ls` | Не заметить alias или функцию, подменяющую команду |
| `man` | Открыть подробную справку | `man ls`, поиск `/size` | Копировать команду из справки без проверки аргументов |
| `help` | Показать справку встроенной команды | `help cd` | Запускать встроенную команду с непроверенными аргументами |
