# Каталоги службы backup-agent

| Данные | Рекомендуемый путь | Основание |
|---|---|---|
| Исполняемый файл | `/usr/local/bin/backup-agent` | локально установленная программа |
| Настройки | `/etc/backup-agent/backup-agent.conf` | системная конфигурация |
| Журналы | `/var/log/backup-agent/` | изменяемые журналы службы |
| Список копий и метаданные | `/var/lib/backup-agent/` | постоянные данные состояния |
| Номер процесса | `/run/backup-agent/backup-agent.pid` | временные данные работающей службы |
